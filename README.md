# Commit

نسخة مستقلة من مشروع Commit جاهزة للرفع إلى GitHub والنشر كـ Vite/React web app.

## تشغيل محليًا

```bash
npm install
npm run dev
```

## بناء نسخة الإنتاج

```bash
npm run build
```

## ملاحظات

- تم الحفاظ على ملفات الواجهة والتصميم الموجودة في النسخة الاحتياطية.
- تمت إزالة اعتماد المشروع على إعدادات Replit الخاصة حتى يعمل كمشروع مستقل.
- أضيفت PWA manifest + service worker لتسهيل تثبيت التطبيق وتحويله لاحقًا إلى APK.
- بيانات التطبيق الحالية محلية في المتصفح، والتحقق من صورة الإثبات تجريبي كما كان في النسخة الأصلية.
